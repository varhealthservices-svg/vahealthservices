# Virginia HealthCare Services — Website

موقع Next.js ساكن مبني من محتوى موقع vahealthcaresvcs.com الأصلي (مستخرج من نسخة wpress احتياطية)
بتصميم مستوحى من ثيم Medify الطبي.

## التشغيل محلياً
npm install
npm run dev

## الرفع على Vercel
1. ادفع هذا المجلد لمستودع GitHub جديد
2. من vercel.com اربط المستودع (Import Project)
3. فيرسل رح يكتشف Next.js أوتوماتيكياً ويبني وينشر

أو مباشرة من الطرفية:
npx vercel
